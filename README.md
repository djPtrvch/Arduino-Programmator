# Arduino Programmator

Как прошивать Arduino, если у вас есть только iPad. Код пишет ИИ (Claude Code, Codex и др.), GitHub собирает прошивки, а маленький Wi-Fi-мост на ESP32 записывает их в плату.

```
iPad ── claude.ai/code ──► GitHub (код)
                             │  GitHub Actions + arduino-cli
                             ▼
                      GitHub Pages: каталог прошивок + manifest.json
                             │
iPad (Safari) ── Wi-Fi ──► ESP32-мост ── ICSP (SPI) ──► Leonardo / Uno / Nano / Mega
                                                          │
iPad ◄──────────────── USB-C (питание + HID-контроллер) ──┘
```

Почему нужен мост: Safari на iPad не поддерживает WebSerial и WebUSB, поэтому браузер не может прошить плату напрямую через USB.

## Состав

| Путь | Что это |
|---|---|
| `firmware/<проект>/` | Скетч (`.ino`) и `project.json`: название, список плат, библиотеки |
| `boards.json` | Профили плат: FQBN, способ прошивки, сигнатура чипа, размер страницы и памяти |
| `bridge/` | Прошивка ESP32-моста: Wi-Fi, веб-интерфейс, ISP-программатор |
| `web/index.html` | Веб-интерфейс. Один и тот же файл открывается с GitHub Pages и с моста |
| `tools/build.py` | Собирает всё в `dist/` |
| `.github/workflows/build.yml` | Сборка при каждом push, публикация на Pages из `main` |

## Подключение моста

Нужны ESP32 DevKit (любой с Wi-Fi) и 5 проводов к 6-пиновому разъёму ICSP на Leonardo.

| ESP32 | ICSP Leonardo | Примечание |
|---|---|---|
| GPIO23 | 4 — MOSI | |
| GPIO19 | 1 — MISO | **через делитель**: MISO → 1 кОм → GPIO19 → 2 кОм → GND (5 В → 3.3 В) |
| GPIO18 | 3 — SCK | |
| GPIO5 | 5 — RESET | |
| GND | 6 — GND | |
| VIN (5V) | 2 — VCC | ESP32 питается от Leonardo, а Leonardo от iPad (один кабель) |

```
ICSP (вид сверху)   1 MISO  ● ●  2 VCC
                    3 SCK   ● ●  4 MOSI
                    5 RESET ● ●  6 GND
```

Мост прошивает плату целиком вместе с загрузчиком (`*.with_bootloader.hex`). Поэтому плату по-прежнему можно прошивать и обычным способом с компьютера.

## Первый запуск

1. **Один раз** прошейте ESP32 с любого компьютера. Подойдёт `dist/bridge/bridge-full.bin` (адрес 0x0, например через https://espressif.github.io/esptool-js/) или Arduino IDE с папкой `bridge/`. После этого мост обновляется по Wi-Fi из своего же интерфейса.
2. На GitHub откройте **Settings → Pages → Source: GitHub Actions**. После слияния в `main` каталог появится по адресу `https://djptrvch.github.io/Arduino-Programmator/`.
3. На iPad подключитесь к Wi-Fi **Arduino-Programmator** (пароль `12345678`) и откройте **http://192.168.4.1**.
4. В «Настройках» введите домашний Wi-Fi. Дальше открывайте **http://programmer.local**: iPad остаётся в интернете, и прошивки берутся прямо из каталога.

## Рабочий цикл на iPad

1. В claude.ai/code попросите: «Добавь проект X для Leonardo» (правила для ИИ описаны в `CLAUDE.md` и `AGENTS.md`).
2. Влейте ветку в `main`. GitHub Actions соберёт прошивку и опубликует каталог (2–5 минут).
3. Откройте `http://programmer.local`, выберите проект и плату, нажмите **«Прошить»**. Мост проверит сигнатуру чипа, сотрёт его, запишет прошивку и сверит записанное.
4. Отключите провода моста (или оставьте подключёнными, они не мешают) и пользуйтесь контроллером через USB-C.

Без домашнего Wi-Fi: скачайте `.hex` с каталога в «Файлы», подключитесь к точке доступа моста и используйте «Прошивка из файла».

## Поддерживаемые платы

Через мост (ISP): Leonardo, Micro, Uno, Nano, Mega 2560. ESP32 пока только собирается, файл можно скачать (прошивка по воздуху — в планах).
Чтобы добавить плату, допишите её в `boards.json` (см. `CLAUDE.md`).
