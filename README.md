# Arduino Programmator

Прошивка Arduino **по USB-C прямо из Chrome на Android** (рассчитано на Pixel 7; на реальном устройстве ещё не проверялось). Код пишет ИИ (Claude Code, Codex и др.), прошивки собирает GitHub, программатор — обычная веб-страница.

```
iPad / Android ── claude.ai/code ──► GitHub (код)
                                       │  GitHub Actions + arduino-cli
                                       ▼
                         GitHub Pages: программатор + каталог прошивок
                                       │
Android (Chrome) ── USB-C ── Leonardo ◄┘  кнопка «Прошить»
```

На iPad страница тоже открывается, но только для просмотра и скачивания: Safari не умеет работать с USB.

## Состав

| Путь | Что это |
|---|---|
| `firmware/<проект>/` | Скетч `.ino` + `project.json` (название, платы, библиотеки) |
| `boards.json` | Профили плат: FQBN, протокол прошивки, сигнатура, размеры памяти |
| `web/index.html` | Программатор: WebUSB + протокол AVR109 (загрузчик Caterina) |
| `tools/build.py` | Собирает всё в `dist/` |
| `.github/workflows/build.yml` | Сборка при каждом push, публикация на Pages из `main` |

## Первый запуск (один раз)

1. Влейте эту ветку в `main` (Pull request → Merge).
2. На GitHub: **Settings → Pages → Source: GitHub Actions**. Затем **Actions → Build firmware → Run workflow** для `main`.
3. Через 3–5 минут программатор будет по адресу **https://djptrvch.github.io/Arduino-Programmator/**. В Chrome на Android: меню ⋮ → «Добавить на главный экран».

## Прошивка

1. Подключите Leonardo к Pixel кабелем **USB-C — USB-C** (кабель с передачей данных). Если Android спросит, какое приложение открыть, — закройте вопрос.
2. Откройте программатор, выберите проект и плату → **«Прошить»** → выберите плату в списке.
3. Плата перезагрузится в загрузчик. Если появится окно «Загрузчик готов» — нажмите кнопку и выберите устройство ещё раз (у загрузчика другой USB-ID, у вас 8 секунд).
4. Прошивка записывается и проверяется (~2–3 с), плата запускается.

Если плата «зависла» и не реагирует: дважды быстро нажмите **RESET** и сразу «Прошить».

## Поддерживаемые платы

- Прошивка из браузера: Leonardo, Micro (ATmega32U4, загрузчик Caterina).
- Только сборка и скачивание: Uno, Nano, Mega, ESP32 (протоколы STK500 / esptool — в планах).

Новые платы и проекты — по правилам в `CLAUDE.md`.
